# 名刺管理君（アプリの画面）

Kamo's BASE の名刺管理アプリ「名刺管理君」の画面です。スマホのホーム画面に置いて使います。

- このリポジトリにあるのは画面（HTML・JavaScript・CSS・アイコン）だけです。名刺のデータ、APIキー、サーバー側のコードは入っていません。
- 名刺のデータは、各社の Google Workspace（スプレッドシート・共有ドライブ）に保存されます。この画面を置いているサイトには届きません。
- 使えるのは、導入した会社の Google アカウントでログインした社員だけです。
