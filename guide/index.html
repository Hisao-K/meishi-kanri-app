名刺管理君 導入手順書

Google Workspace の申し込みから、社員のスマホで使い始めるまで

はじめに

名刺管理君は、スマホで名刺を撮るだけで、名前・会社・電話番号などを読み取って会社の名刺台帳に登録するアプリです。登録した名刺は、同じ会社の社員だけが見られます。ほかの会社の人や、Kamo's BASE（提供元）は見られません。

名刺の台帳と画像は、御社の Google Workspace の中（共有ドライブ）に保存されます。この手順書では、Google Workspace を契約していない状態から、社員のスマホで使い始めるまでを順に説明します。

用意するもの

  • パソコン（手順1〜9はパソコンで行います）
  • 会社のドメイン（例：example.co.jp）。持っていない場合は、手順1の申し込みの途中で取得できます
  • クレジットカード（Google Workspace と Gemini API の支払いに使います）
  • Kamo's BASE からお渡しする「プログラムのコピー用リンク」
  • 社員のスマホ（iPhone または Android）

  4. Gemini の API キーを作る代表者
  5. プログラムをコピーする代表者
  6. プログラムに設定を入れる代表者
  7. 台帳の見出しを作る（初回の承認）代表者

  9. 社員に配るリンクを作る代表者
  10. スマホに入れてログインする社員全員

「代表者」について 手順1〜9は、会社を代表する1つのアカウント（以下「代表アカウント」）で行います。名刺を読み取るプログラムは、このアカウントの権限で動きます。登録した名刺は、このアカウントの Google 連絡先にも入ります。退職などで使えなくならないアカウント（社長や会社の共用アカウント）を選んでください。

1. Google Workspace を申し込む

Google Workspace は、会社のメールアドレス（例：yamada@example.co.jp）で使える Google の有料サービスです。名刺管理君は、Google Workspace の共有ドライブとスプレッドシートに名刺を保存します。

  1. パソコンで Google Workspace の申し込みページ を開きます。
  2. 会社名 を入れ、自分を含む従業員の数 を選び、地域 が 日本 になっていることを確かめて、次へ を押します。
  3. このあとは画面の案内に沿って、連絡先、ドメイン、管理者のアカウント（ユーザー名とパスワード）、支払い情報を入れます。
    • ドメイン：会社のドメインを持っていれば、それを入れます。持っていなければ、その場でドメインを購入できます。
    • 管理者のアカウント：ここで作るアカウントが、この手順書でいう「代表アカウント」です。
    • プラン：Business Starter で使えます。
無料試用について 14日間、10人まで無料で試せます。申し込みのときに支払い情報の登録が必要で、試用が終わると自動で有料に切り替わります。
ドメインまわりの期限に注意 ・申し込みの途中でドメインを購入した場合：確認のメールが届きます。15日以内に返信しないとドメインが止まり、メールが使えなくなります。購入したドメインはキャンセルできません。
・すでに持っているドメインを使う場合：そのドメインが御社のものであることの証明が必要です。Google の設定画面に出る確認用の文字列を、ドメインを買った会社の設定画面に登録します。申し込んだら、早めに済ませてください。
詳しくは Google のヘルプ 申し込み時にドメインを購入する・ドメインの所有権を証明する を見てください。
Gmail のアドレスでは申し込まない Gmail のアドレス（@gmail.com）でも申し込めますが、その場合は1人でしか使えず、社員を追加できません。名刺管理君を会社で使うには、会社のドメインで申し込んでください。

2. 社員のアカウントを作る

名刺管理君を使う社員ごとに、会社のメールアドレス（例：suzuki@example.co.jp）を作ります。

  1. パソコンで 管理コンソールのユーザー一覧 を開きます（代表アカウントでログイン）。
  2. 新しいユーザーの追加 を押します。
  3. 姓名メインのメールアドレス を入れ、新しいユーザーの追加 を押します。
  4. 追加が終わると、ログインの案内の画面が出ます。パスワードをコピー で控えて本人に伝えるか、プレビューして送信 で本人のメールに送り、完了 を押します。
費用について社員のアカウントを1つ作るごとに、Google Workspace の料金が1人分かかります。

3. 共有ドライブ・フォルダ・スプレッドシートを作る

名刺の台帳（スプレッドシート）と画像を入れる場所を作ります。共有ドライブに入れたものは、メンバーに加えた社員全員が見られます。

3-1. 共有ドライブを作る

  1. パソコンで Google ドライブの共有ドライブ を開き、左上の 新規 を押します。
  2. 名前に 名刺管理 と入れ、作成 を押します。

3-2. 社員をメンバーに加える

  1. 作った共有ドライブを開き、メンバーを管理 を押します。
  2. ユーザーやグループを追加 に社員のメールアドレスを入れ、送信 を押します。権限は最初に選ばれているもの（コンテンツ管理者）のままでかまいません。
アプリで見るだけなら名刺管理君のアプリで名刺を見たり登録したりするだけなら、共有ドライブのメンバーに入っていなくても使えます。メンバーに加えると、スプレッドシートや画像をドライブで直接見られるようになります。

3-3. フォルダとスプレッドシートを作る

  1. 共有ドライブ 名刺管理 を開いたまま、新規 ＞ 新しいフォルダ で、名刺画像 という名前のフォルダを作ります。
  2. 同じく 新規 ＞ Google スプレッドシート ＞ 空白のスプレッドシート で、スプレッドシートを作ります。名前は 名刺管理 にします（ほかの名前でもかまいません）。

3-4. IDを控える

手順6で使うため、スプレッドシートとフォルダの「ID」を控えます。IDは、開いたときのブラウザのアドレス欄に入っている英数字です。黄色の部分をコピーして、メモ帳などに貼っておいてください。

スプレッドシートのID（スプレッドシートを開いたときのアドレス）

https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz0123456789/edit

フォルダのID（フォルダ 名刺画像 を開いたときのアドレス）

https://drive.google.com/drive/folders/1XyZaBcDeFgHiJkLmNoPqRsTuVwX

上の英数字は例です。御社のものは、文字も長さも違います。

3-5. 社外の人と共有できないようにする（おすすめ）

社員がうっかり名刺の台帳や画像を社外の人と共有しないよう、会社全体で社外への共有を止めておきます。

  1. 管理コンソール を開き、アプリ ＞ Google Workspace ＞ ドライブとドキュメント を開きます。
  2. 共有設定 の 共有オプション で、社外との共有を オフ にして保存します。

詳しくは Google のヘルプ 組織の外部共有を管理する を見てください。社外の取引先とドライブでファイルを共有している場合は、オフにすると共有できなくなるので、社内で相談してから決めてください。

4. Gemini の API キーを作る

名刺の文字の読み取りと「AIに相談」には、Google の AI（Gemini）を使います。使うための鍵（API キー）を、代表アカウントで作ります。

4-1. API キーを作る

  1. 代表アカウントでログインしたまま、Google AI Studio の API キーのページ を開きます。
  2. 右上の API キーを作成 を押します。
  3. キー名の設定 に 名刺管理君 と入れ、キーを作成 を押します。インポートしたプロジェクトを選択 は、最初に選ばれているままでかまいません。
  4. 一覧に増えたキーの行で、右側の四角が2つ重なったアイコン（API キーのコピー）を押すと、キーがコピーされます。メモ帳などに貼って控えます（手順6で使います）。

4-2. 有料枠にする（必ず行ってください）

一覧の 請求階層 の欄を見ます。Tier 1 などと出ていれば、有料枠になっています。無料枠のままになっている場合は、その欄から支払い方法を登録します。最初に5ドル（約750円）以上を前払いします。

無料枠のままでは使わないでください 無料枠では、送った内容（名刺の画像や文字）が Google のサービス改善に使われ、人が読むこともあると Google の利用規約に書かれています。名刺は個人情報なので、必ず有料枠にしてください。有料枠では、送った内容はサービス改善に使われません（Gemini API の利用規約）。
前払いの残高に注意 前払いの残高がなくなると、API キーが止まり、名刺の読み取りができなくなります。左の 利用額 で、ときどき残高を確かめてください。前払いした分は、使わないまま12か月たつと失効します（Gemini API の課金）。

5. プログラムをコピーする

  1. 代表アカウントでログインしたまま、Kamo's BASE からお渡しした「プログラムのコピー用リンク」を開きます。
  2. プロジェクトの詳細 の画面が開きます。右上の コピーを作成（四角が2つ重なった形のボタン）を押します。別の画面が開いたときは、左の 概要（ⓘ のアイコン）を押すと、この画面になります。
  3. コピーが開きます。左上の名前を押すと、名前を変えられます。名刺管理君 にしておくとわかりやすいです。
コピーしたプログラムは御社のものコピーは代表アカウントのマイドライブに作られ、御社のアカウントで動きます。Kamo's BASE からは見えません。

6. プログラムに設定を入れる

手順3・4で控えた値を、プログラムに登録します。

  1. コピーしたプログラムの画面で、左の歯車 プロジェクトの設定 を押します。
  2. 下の方の スクリプト プロパティ で、スクリプト プロパティを追加 を押し、次の5つを1つずつ入れます。プロパティ に左の名前を、値 に右の値を入れます。
プロパティ値
GEMINI_API_KEY手順4で作った API キー
SPREADSHEET_ID手順3-4で控えたスプレッドシートのID
DRIVE_FOLDER_ID手順3-4で控えたフォルダのID
GOOGLE_CLIENT_ID456836034516-dsddn674o4pv00tng23rj3h22c3u7oaa.apps.googleusercontent.com
（全社共通の値です。このままコピーしてください）

API キーは人に見せないAPI キーは、御社の Gemini の利用料金につながる鍵です。メールやチャットに貼ったり、人に見せたりしないでください。

7. 台帳の見出しを作る（初回の承認）

プログラムを一度動かして、スプレッドシートに見出しの行を作ります。このとき、プログラムがドライブや連絡先を使うことを、代表アカウントで許可します。

  1. 左の <>（エディタ）を押し、ファイルの一覧から main.gs を押します。
  2. 上の関数の選択欄で setup を選び、実行 を押します。
  3. 初めて実行するときは、プログラムがドライブ・スプレッドシート・連絡先などを使ってよいか、許可を求める画面が出ます。代表アカウントを選び、内容を確かめて許可します。許可は最初の1回だけです。
  4. 下に 実行ログ が開き、setupSheet: ヘッダー行を作成/更新しました。 と出たら完了です。スプレッドシートの1行目に「登録日時」「名前(日本語)」などの見出しが入ります。

8. アプリとして公開する

  1. 右上の デプロイ ＞ 新しいデプロイ を押します。
  2. 次のようになっているか確かめて、デプロイ を押します。
    • 種類の選択：ウェブアプリ（出ていなければ、歯車を押して選びます）
    • 次のユーザーとして実行：自分（代表アカウント）
    • アクセスできるユーザー：全員
  3. 許可を求める画面が出たときは、手順7と同じように許可します。
  4. 表示された ウェブアプリ の URL（https://script.google.com/macros/s/…/exec）をコピーして控えます。手順9でも使います。
  5. 左の歯車 プロジェクトの設定 を押し、スクリプト プロパティを編集 ＞ スクリプト プロパティを追加 で、次の1つを足して スクリプト プロパティを保存 を押します。
    プロパティ値
    API_URLいまコピーしたウェブアプリの URL（https://script.google.com/macros/s/…/exec）
    これを入れるまでは、だれもログインできません。プログラムは、ログインがこの URL あてに行われたものかを確かめます（ほかの人が用意した偽の接続先でログインさせられても、その情報を御社のプログラムで使わせないため）。
「全員」にしても、名刺は誰でも見られるわけではありませんスマホのアプリからプログラムに届くようにするために「全員」にします。プログラムは、届いた要求ごとに「御社のドメインの Google アカウントでログインしているか」を確かめ、違う場合は何も返しません。

9. 社員に配るリンクを作る

次のURLの ここにウェブアプリのURL の部分を、手順8で控えたURLに置き換えます。これが「設定用リンク」です。社員にメールやチャットで送ります。

https://hisao-k.github.io/meishi-kanri-app/?api=ここにウェブアプリのURL

例：

https://hisao-k.github.io/meishi-kanri-app/?api=https://script.google.com/macros/s/AKfyc…/exec
設定用リンクを送ってよい相手設定用リンクを開いても、御社のアカウントでログインできなければ名刺は見られません。それでも、送る相手は社員だけにしてください。

10. スマホに入れてログインする

ここからは、名刺管理君を使う社員それぞれが、自分のスマホで行います。

  1. 手順9の「設定用リンク」を、スマホで開きます。iPhone は Safari、Android は Chrome で開いてください。ログイン の画面が出ます。
  2. ログインする前に、この画面をホーム画面に追加します。
    • iPhone（iOS 26）：Safari の その他 ボタン ＞ 共有 を押し、下へ動かして ホーム画面に追加 を押します。Webアプリとして開く をオンにして、追加 を押します。
    • iPhone（iOS 27）：iOS 26 とほぼ同じです。ボタンの名前が ページメニュー、スイッチの名前が ウェブアプリとして開く に変わっています。
    • iPhone（iOS 18）：Safari の共有ボタン（四角から上向きの矢印が出ている形）を押し、下へ動かして ホーム画面に追加 を押します。
    • Android：Chrome の右上の︙（縦に点が3つ）を押し、メニューからホーム画面に追加する項目を選びます。
    iPhone の操作は、iOS の版によって表示が少し違います。詳しくは Apple のサポート Safari で Web サイトをホーム画面に追加する を見てください。
  3. ホーム画面に増えた 名刺管理君 のアイコンから開き、Google でログイン を押して、会社のアカウント（手順2で作ったもの）でログインします。
ホーム画面のアイコンから開いて、もう一度ログイン iPhone では、ホーム画面のアイコンから開いたアプリと Safari は、ログインの状態を別々に持っています。Safari でログインしていても、アイコンから開いたら、もう一度ログインしてください。
「はじめの設定」が出たとき 設定用リンクを使わずに開くと、はじめの設定 の画面が出ます。ホーム画面のアイコンを削除し、設定用リンクから開き直して、もう一度ホーム画面に追加してください。

11. 使い方

名刺を1枚登録する

  1. 登録 を押し、片面（表だけ）か 両面（表と裏）を選びます。
  2. 表面を撮る（両面なら 裏面を撮る も）を押して名刺を撮り、登録する を押します。
  3. 読み取った内容が出たら完了です。続けて 顔写真を追加 や コメントを追加 もできます。

名刺をまとめて登録する

交流会などで名刺がたくさんあるときに使います。全部の名刺に同じコメント（例：「守成クラブ 例会で名刺交換」）を付けられます。

  1. まとめて を選び、📷 1枚目の表を撮る を押します。
  2. 表を撮ると、表の右に 📷 裏を撮る、下に 📷 次の名刺（2枚目）の表を撮る が出ます。裏がある名刺は裏を撮り、なければ次の名刺へ進みます。
  3. 全部撮ったら、必要ならコメントを書き、まとめて登録する を押します。

すでに登録してある名刺（名前と会社名が同じもの）は、二重に登録されず「登録済みの名刺でした」と出ます。

名刺を探す

  1. 探す を押し、探す項目（名前・会社・フリー）にチェックを入れます。
  2. 言葉を入れて 探す を押します。🎤 を押すと、声でも入れられます。
  3. 出てきた名刺を押すと、詳しい内容と名刺の画像が見られます。

AIに相談する

やりたいことを文章で書くと、登録した名刺の中から合いそうな会社・人を選びます。判断の材料は、名刺とコメントに書いてあることだけです。

使い終わったら

右上の 閉じる を押すとログアウトし、画面の名刺も消えます。スマホを人に渡すときなどに使ってください。次に開いたときは、ログインからになります。

12. 困ったとき

こんなとき確かめること
アプリを開くと はじめの設定 が出る設定用リンクから開き直してください（手順10）。
ログインを確認できませんでした。 と出る会社のアカウント（手順2で作ったもの）でログインしているか確かめてください。代表者は、手順6の ALLOWED_DOMAIN が御社のドメインと同じつづりか確かめてください。
E004: 名刺情報の読み取りに失敗しました。 と出る明るい場所で、名刺が画面いっぱいに写るように撮り直してください。何度撮っても出る場合は、代表者が手順4の API キーと前払いの残高を確かめてください。
E002: 同じ名刺がすでに登録されています。 と出る名前と会社名が同じ名刺が、すでに登録されています。登録済みの名刺を開く で中身を見られます。
E005: スプレッドシートへの書き込みに失敗しました。 と出る代表者が、手順6の SPREADSHEET_ID と、手順7（setup の実行）が済んでいるかを確かめてください。
E003: 画像の保存に失敗しました。 と出る代表者が、手順6の DRIVE_FOLDER_ID を確かめてください。フォルダが共有ドライブの中にあり、代表アカウントがその共有ドライブのメンバーである必要があります。
